# 🎯 Test Quest

**Learn. Test. Discover.**

A personal learning wiki documenting my journey into software testing and my preparation for the Software Testing training program at **ENI, a French IT school**.

Here you'll find my notes, useful resources, tutorials, testing concepts, and practical exercises as I learn.

## 📚 What's inside?

- Software testing fundamentals and methodologies
- ISTQB concepts and terminology
- Tutorials, documentation, and useful links
- Practical exercises and personal projects
- Notes, experiments, and things I'm still figuring out

## 🌍 Languages

Content can be in French or English, depending on the topic, context, and available resources.

## 🧭 Structure

The repository is organized by topic and will evolve as I progress through my learning journey.

## 🤷 A quick disclaimer

This is a personal project, built around my own needs and learning style. The way I organize things may not work for everyone, and that's perfectly fine.

I'm making it public because sharing knowledge is a good thing. If you find something useful here, great! But creating a resource for others isn't really the point — I'm primarily doing this for myself.

I'm learning as I go, so expect the occasional mistake, misunderstanding, outdated information, or even complete nonsense. Nothing here should be treated as an authoritative source. Double-check important information against reliable sources and official documentation.

This is an independent project, not affiliated with ENI, and its content does not represent official ENI course materials.

**If it's useful to you, great. If you spot a mistake, feel free to let me know!**
